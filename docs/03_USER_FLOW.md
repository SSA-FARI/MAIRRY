# 03. 사용자 흐름

## 전체 흐름

~~~text
초기 설정
  → 대시보드
  → 계약서 업로드
  → AI 분석
  → 추출 결과 검수
  → 계약 확정
  → 대시보드 갱신
  → 추가지출 시뮬레이션 또는 AI 질문
~~~

## 정상 흐름

| 단계 | 사용자 행동 | 시스템 반응 |
|---|---|---|
| 1. 초기 설정 | 결혼일·가용자금 입력 | 계획 저장 후 대시보드 이동 |
| 2. 업로드 | 계약서 선택 | 파일 검증 후 분석 시작 |
| 3. 분석 | 대기 | 진행 상태 표시 |
| 4. 검수 | 금액·날짜·조건 확인 및 수정 | 수정값 임시 보관 |
| 5. 확정 | 계약 확정 선택 | 확정값 저장 및 계산 반영 |
| 6. 확인 | 대시보드 조회 | 자산 카드·타임라인 갱신 |
| 7. 시뮬레이션 | 추가 금액 입력 | 기존/변경 예상 잔액 비교 |
| 8. 질문 | 자연어 질문 입력 | 계약 근거 또는 계산값과 답변 표시 |

## 예외 흐름

### 파일 오류

- 미지원 형식 또는 용량 초과 시 업로드 전에 안내한다.
- 업로드 실패 시 입력값을 유지하고 재시도 버튼을 제공한다.

### AI 분석 실패

- 상태를 FAILED로 표시한다.
- 재분석 또는 직접입력 중 하나를 선택하게 한다.

### 정보 누락

- 금액·날짜를 찾지 못한 필드는 비워두고 확인 필요로 표시한다.
- 필수값이 비어 있으면 확정할 수 없도록 안내한다.

### 근거 없는 질문

- “등록된 계약 및 계산 결과에서 확인할 수 없습니다.”라고 응답한다.
- 일반 상식이나 법률 판단으로 답을 확장하지 않는다.

## 데모 흐름

1. 가용자금 30,000,000원 입력
2. 샘플 웨딩홀 계약서 업로드
3. 잔금일 한 항목을 수정하고 확정
4. 남은 지출과 예상 잔액 확인
5. 추가지출 3,000,000원 시뮬레이션
6. “웨딩홀 잔금일이 언제야?” 질문
