# 02. MVP 범위

## 골든 패스

> 초기 설정 → 계약서 업로드 → AI 분석 → 사용자 검수·확정 → 대시보드 → 시뮬레이션·질문

## Must Have

| 기능 | 완료 조건 |
|---|---|
| 초기 설정 | 결혼일과 현재 가용자금 저장·수정 |
| 문서 업로드 | PDF/JPG/PNG 1건 업로드 및 상태 표시 |
| AI 분석 | 업체명, 총액, 지급항목, 취소조건, 근거 추출 |
| 결과 검수 | 추출값 수정 후 확정 가능 |
| 계약 관리 | 계약 목록·상세 조회, 확정 계약 수정·삭제, 삭제 후 원문 재검수 |
| 금융 대시보드 | 가용자금, 남은 지출, 예상 잔액, 가까운 지급일 표시 |
| 지급 타임라인 | 확정 지급항목을 날짜순 표시 |
| 시뮬레이션 | 추가지출 1건의 전후 잔액 비교 |
| AI 질문 | 계약 및 계산 질문에 근거 기반 답변 |
| 오류 처리 | 분석 실패 안내 및 재시도 |

## Should Have

- 스드메 견적서 지원
- 월별 잔액 차트
- 필드별 확인 필요 표시

## Won't Have

- 마이데이터·계좌·카드 연동
- 금융상품 추천과 대출 신청
- 법률 판단과 불공정 계약 판정
- 커플 공동편집 권한
- 웨딩업체 비교·예약·결제
- 결혼 이후 가계부
- 푸시·문자·메일 알림

## 단순화 기준

- 기본 지원 문서는 웨딩홀 계약서다.
- 데모 사용자 한 명을 사용하고 복잡한 인증은 제외한다.
- 자산은 사용자가 직접 입력한 현재 가용자금만 사용한다.
- 확정된 미지급 금액만 지출로 계산한다.
- 확정 계약을 수정하면 변경된 지급항목을 즉시 금융 계산에 반영한다.
- 계약 삭제는 확정 데이터만 제거하고 원본 Document를 재검수 가능한 상태로 보존한다.
- AI 연동 실패 시 데모 샘플의 사전 분석 결과를 사용할 수 있다.

## 컷오프

1. Day 1에 골든 패스가 없으면 Should 기능을 모두 제거한다.
2. Day 2에 AI가 불안정하면 사전 분석 Fallback을 확정한다.
3. Day 3에는 신규 기능을 추가하지 않는다.
